# weather-forecast
Location Weather Forecast

## 🌦 Weather Forecast App (React.js)
- A modern, responsive weather forecasting web app built using React.js that fetches real-time weather data based on the user's current location or manual input. Designed for fast rendering, intuitive UI, and cloud deployment experience.

## 🚀 **Features**
- Live weather data from OpenWeather API
- Auto-detect user location
- Search weather by city
- Clean, modern UI
- Responsive across devices

## 🛠 **Tech Stack**
- Frontend: React.js, HTML, CSS, JavaScript
- API: OpenWeather API
- Cloud & Deployment: Netlify, AWS S3
- Version Control: Git & GitHub
